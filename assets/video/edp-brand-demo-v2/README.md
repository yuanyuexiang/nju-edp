## 使用说明

保留“创意提案”和“非正式招生发布”标记。没有使用校徽、教授肖像、学员见证或虚构校园/课堂实拍，也未编写学费、日期、证书或效果承诺。“长三角 · 制造与科技企业”是 `01` 建议的服务重点，作为创意语境出现，不是对中心业务范围的官方描述。个人提升下的三个类别来自已核验的[南京大学 EDP 个人提升项目列表](https://edp.nju.edu.cn/34636/listm.htm)。文案已对照 `13-合规禁用词与替代表述.md`。

正式招生版本应替换为具体项目的已审批文案，按需要加入获准的校园、教师和课程素材及真实报名入口。

## 重新生成

在 macOS 安装 Python 3、Pillow、NumPy、ffmpeg，并具备系统 Tingting 语音后，从仓库根目录执行：

```sh
python3 assets/video/edp-brand-demo-v2/build_video.py
```

修改脚本中的 `SCENES` 可调整口播和字幕；修改 `scene_layer` 可调整主视觉。运行会覆盖本目录中的成片与封面，制作新版本前请复制整个目录。`production/` 保存中间音频、分镜图和配音时间信息（`narration.json` 含每幕口播的加速比 `tempo`），不纳入版本控制。

验收：已查看全部五幕关键帧，文字均在安全边距内；成片已通过 ffprobe 规格检查及 ffmpeg 全片解码检查；各幕口播加速比不超过 1.2。抽帧检查不等于逐帧或完整听审。
