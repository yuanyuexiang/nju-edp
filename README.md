# 南京大学 EDP 招生营销研究包

更新日期：2026-09-02

本文件夹包含一套可直接用于内部讨论和执行的招生营销方案。研究中的公开信息均附来源；涉及南京大学 EDP 尚未公开或无法核验的价格、名额、开班日期、师资、证书、校友权益等信息，必须以中心最终审批版本为准。

## 文件说明

- `01-市场与营销战略报告.md`：市场、需求、竞品、定位、产品与渠道策略、合规和预算建议。
- `02-90天招生作战计划.md`：按周执行动作、角色分工、阶段门槛和复盘机制。
- `03-内容选题与活动日历.csv`：12 周内容与活动排期，可导入表格工具。
- `04-线索CRM模板.csv`：统一记录个人与企业客户线索。
- `05-营销指标看板.csv`：从曝光到缴费的漏斗指标及计算方式。
- `06-访谈提纲与调研问卷.md`：先验证需求，再扩大投放。
- `07-来源清单.md`：本次研究采用的主要公开资料。
- `08-四大内容平台运营专项研究.md`：微博、小红书、抖音、公众号的定位、内容、获客、转化、团队和指标。
- `09-四平台30天发布排期.csv`：可直接执行的首月内容排期与复用关系。

## 建议的启动顺序

1. 用 2 周完成 20 位潜在学员、10 位企业 HR/组织发展负责人和 5 位老学员访谈。
2. 选一个主推项目，确认招生目标、学费、开班时间、席位和合规口径。
3. 上线一场主题闭门会和一份“管理者诊断”，用真实线索验证卖点。
4. 只有当“有效线索→深度咨询”达到 25% 以上时，才扩大付费投放。
5. 四个平台先用 30 天完成小规模验证，不以粉丝数判断成败，以有效咨询和申请贡献判断。
