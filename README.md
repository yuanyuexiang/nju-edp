# 南京大学 EDP 招生营销研究包

更新日期：2026-09-17

本文件夹包含一套可直接用于内部讨论和执行的招生营销方案。研究中的公开信息均附来源；涉及南京大学 EDP 尚未公开或无法核验的价格、名额、开班日期、师资、证书、校友权益等信息，必须以中心最终审批版本为准。

## 文件说明

研究与计划：

- `01-市场与营销战略报告.md`：市场、需求、竞品、定位、产品与渠道策略、合规和预算建议。5.1 节含问题型入口版的备选主张。
- `02-90天招生作战计划.md`：按周执行动作、角色分工、阶段门槛和复盘机制。
- `06-访谈提纲与调研问卷.md`：先验证需求，再扩大投放。
- `07-来源清单.md`：本次研究采用的主要公开资料及复核记录。
- `08-四大内容平台运营专项研究.md`：微博、小红书、抖音、公众号的定位、内容、获客、转化、团队和指标；3.2 节定义统一渠道码格式。
- `10-招生业务系统建设决策研究.md`：是否建设招生系统、校内系统衔接、轻量 CRM 选型、投入测算与 30 天试点验收。
- `13-合规禁用词与替代表述.md`：发布前逐条对照的禁用、需审批件和附条件表述清单。
- `14-三人团队最小执行版.md`：专职人员不足 4 人时的角色合并、产量缩减和 90 天节奏。
- `15-落地页信息清单与企业定制一页纸模板.md`：项目落地页 14 项核验清单和企业定制一页项目假设模板。
- `16-招生渠道深度调研.md`：南大自身承接现状、竞品渠道观察、平台与行业数据、校友与 B2B 入口清单、搜索与非官方代理、30 天验证方案；每项标注证据等级。

- `18-招生渠道API对接可行性调研.md`：逐平台核验评论、私信、广告线索与客户关系 API；明确小红书准入、抖音和微信权限、未核实范围、人工兜底与接口验收。

- `19-营销内容生产方案与POC.md`：独立的内容生产服务方案；资料与品牌模板、ComfyUI/RunningHub 候选、图像与视频分工、一文三海报一视频 POC、审核和成本验收。

- `20-竞品商学院渠道运营深度调研.md`：六家竞品的小红书、抖音、公众号、视频号与咨询承接；账号归属、近期样本、付费采购证据、内容模板与南大试点建议，明确学院与 EDP/MBA 的区别。

- `21-南京大学EDP主流渠道现状与账号台账.md`：中心官网、公众号、视频号、抖音、小红书、微博等 12 类主流渠道核验；注册与运营分列，记录历史账号、校级账号边界、报名断点、同名第三方页面及内部补验清单。

## 建议的启动顺序

1. 用 2 周完成 20 位潜在学员、10 位企业 HR/组织发展负责人和 5 位老学员访谈。
2. 选一个主推项目，确认招生目标、学费、开班时间、席位和合规口径；对外内容先过 `13`，落地页按 `15` 逐项核验；先按 `16` 第二节修复官网承接，再导流。
3. 上线一场主题闭门会和一份“管理者诊断”，用真实线索验证卖点。
4. 只有当“有效线索→深度咨询”达到 25% 以上时，才扩大付费投放。
5. 四个平台先用 30 天完成小规模验证，不以粉丝数判断成败，以有效咨询和申请贡献判断。
6. 系统建设先按 `10` 核验现有校内能力，再决定是否配置轻量 CRM；配置规格按 `17`，优先试点一个项目，依据使用记录和成本收益决定扩展。
7. 专职人员不足 4 人时，整体按 `14` 缩减执行，不按 `02`、`08` 的完整产量硬撑。
