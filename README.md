# 南京大学 EDP 招生营销研究包

更新日期：2026-09-11

本文件夹包含一套可直接用于内部讨论和执行的招生营销方案。研究中的公开信息均附来源；涉及南京大学 EDP 尚未公开或无法核验的价格、名额、开班日期、师资、证书、校友权益等信息，必须以中心最终审批版本为准。

## 建议的启动顺序

1. 用 2 周完成 20 位潜在学员、10 位企业 HR/组织发展负责人和 5 位老学员访谈。
2. 选一个主推项目，确认招生目标、学费、开班时间、席位和合规口径；对外内容先过 `13`，落地页按 `15` 逐项核验；先按 `16` 第二节修复官网承接，再导流。
3. 上线一场主题闭门会和一份“管理者诊断”，用真实线索验证卖点。
4. 只有当“有效线索→深度咨询”达到 25% 以上时，才扩大付费投放。
5. 四个平台先用 30 天完成小规模验证，不以粉丝数判断成败，以有效咨询和申请贡献判断。
6. 系统建设先按 `10` 核验现有校内能力，再决定是否配置轻量 CRM；优先试点一个项目，依据使用记录和成本收益决定扩展。
7. 专职人员不足 4 人时，整体按 `14` 缩减执行，不按 `02`、`08` 的完整产量硬撑。
